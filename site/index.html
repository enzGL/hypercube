Como começar

Get started

  1. Instale um agente, por exemplo o Claude Code. O Hypercube acha sozinho o que você já tem.
    Install an agent, such as Claude Code. Hypercube finds what you already have.
  2. Baixe o Hypercube na página de versões e abra.
    Download Hypercube from the releases page and open it.
  3. Escolha a pasta do projeto e abra o primeiro agente. O Hiper, o mascote, guia o resto.
    Pick your project folder and open the first agent. Hiper, the mascot, guides the rest.
  4. Quer o roteador gratuito? Instale o Node.js e ligue na tela Roteador.
    Want the free router? Install Node.js and turn it on in the Roteador screen.
